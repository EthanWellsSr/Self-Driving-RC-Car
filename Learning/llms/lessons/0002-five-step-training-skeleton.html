Training Models · Lesson 2

The five-step training skeleton

You already wrote this once, for GTSRB. The point of this lesson: those same five steps train almost any model in TensorFlow. Learn the skeleton and you're no longer copying a tutorial — you're adapting a pattern.

The whole pattern

Load → Define → Compile → Fit → Save. Steps 3–5 stay nearly identical every time. You swap steps 1–2 and two settings to fit a new problem.

The five steps, mapped to code you already wrote

1. Load — get data into a Dataset

Read your data and split it into a training set and a validation set.

train_ds = tf.keras.utils.image_dataset_from_directory("GTSRB/Train", subset="training", ...)
val_ds   = tf.keras.utils.image_dataset_from_directory("GTSRB/Train", subset="validation", ...)

2. Define — stack the layers

Describe the model as an ordered stack. The layer types suit the data (images → Conv2D); the last layer suits the output.

model = tf.keras.Sequential([
    tf.keras.layers.Input(shape=(32, 32, 3)),
    tf.keras.layers.Conv2D(32, 3, activation="relu"),
    ...
    tf.keras.layers.Dense(43, activation="softmax"),   # 43 classes out
])

3. Compile — set how it learns

Pick the optimizer (does the correcting), the loss (the wrongness score), and metrics to watch. Passed to compile().1

model.compile(optimizer="adam", loss="sparse_categorical_crossentropy", metrics=["accuracy"])

4. Fit — run the loop

One call runs the whole guess→check→adjust grind for N epochs, scoring on the validation set each pass.

model.fit(train_ds, validation_data=val_ds, epochs=10)

5. Save — keep the trained model

model.save("gtsrb_model.keras")

Why this is powerful: what actually changes

Steps 3, 4, 5 are the same for a spam filter, a house-price predictor, or a sign classifier. To move to a new problem you change just four things:

SwapDriven by
Data loader (step 1)your data type (images / tabular / text)
Hidden layers (step 2)the problem (Conv2D / Dense / LSTM)
Last layerthe output shape
Lossthe task type

The one rule to remember

The last layer and the loss must agree. Multi-class → Dense(N,"softmax") with sparse_categorical_crossentropy. Yes/no → Dense(1,"sigmoid") with binary_crossentropy. Predict a number → Dense(1) with mse. Get those two right and the skeleton carries the rest. Full table in the cheat sheet →

Self-check (recall before revealing)

Name the five steps in order.

Load, Define, Compile, Fit, Save.

Moving to a new problem, which two steps stay basically unchanged?

Compile and Fit — the optimizer/fit calls are the same shape.

For predicting a house price (a number), what last layer and loss?

Dense(1) with mse loss.

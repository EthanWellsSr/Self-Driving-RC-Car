TensorFlow / Keras training skeleton

Every training job is these five steps. Steps 3–5 barely change; you swap steps 1–2 and two settings to fit a new problem.

The skeleton

import tensorflow as tf

# 1. LOAD — get data into a Dataset, split train/validation
train_ds = tf.keras.utils.image_dataset_from_directory(..., subset="training",  ...)
val_ds   = tf.keras.utils.image_dataset_from_directory(..., subset="validation", ...)

# 2. DEFINE — stack layers suited to the data
model = tf.keras.Sequential([
    tf.keras.layers.Input(shape=(...)),
    # ...hidden layers...
    tf.keras.layers.Dense(N_OUTPUTS, activation=LAST_ACTIVATION),
])

# 3. COMPILE — how it learns (nearly always the same shape)
model.compile(optimizer="adam", loss=LOSS, metrics=["accuracy"])

# 4. FIT — the training loop
model.fit(train_ds, validation_data=val_ds, epochs=N)

# 5. SAVE — persist the trained model
model.save("model.keras")

What you swap per problem

PieceDepends on
Data loader (step 1)data type — images: image_dataset_from_directory; tabular/CSV: tf.data; text: a text loader
Hidden layers (step 2)problem — images: Conv2D; tabular: Dense; sequences/text: LSTM/attention
Last layer + lossthe output type — see table below (these two must agree)
